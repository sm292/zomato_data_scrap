# Kolkata Restaurant Data Collection

A Python-based restaurant data collection
and preprocessing project focused on Kolkata.

## Technologies
- Python
- BeautifulSoup
- Requests
- Pandas
- OpenStreetMap
- Overpass API

## Features
- Restaurant data extraction
- Cuisine classification
- Address collection
- Restaurant website collection
- Data cleaning
- Duplicate detection
- Missing value analysis
- CSV and Excel export

## Target Dataset
500–1,000 restaurants.

## Data Source
OpenStreetMap contributors.

https://www.openstreetmap.org/copyright
